# アプリ名
ハナシドキ

## 概要
RUNTEQの学習の一環として作成したWebアプリです。
話しかけようと思ったら「今忙しいからまた後で」と言われたり、タイミングが来たと思ったら離席中だったり、なかなか話しかけられないということはありませんか？
「今話しかけていい？」を気にしなくてもいいように、相手の状況を可視化することで、話しかけるタイミングを図るアプリです。

## 使用技術
- Ruby 3.4.8
- Ruby on Rails 8.1.0
- PostgreSQL
- Tailwind CSS

## 機能
- ログイン認証処理
- ステータス編集
- ユーザー新規登録機能
- 投稿の一覧表示（縦3列表示）
- フラッシュメッセージの実装
　→ログインおよび新規登録に成功したとき、バリデーションに引っかかったとき、ステータスを編集したとき

## 工夫した点や気づき
RUNTEQで学習した内容の復習も兼ねて、今回はログイン機能・ステータス新規作成・編集を実装しました。
カリキュラムの進捗の関係でDeleteまで実装できなかったが、ここまで作れたことでも良いアウトプットの練習になったと思います。
バリデーションエラーの場合は、その詳細も表示するように設定したことで、ユーザーにどこが誤っているかを明示できると、正しい情報を入力してもらいやすくなることに気づきました。
また、ログイン認証のライブラリとしてSorceryを実装したことで、ログイン認証機能を自分で書く必要がないこと、ログイン済みの状態を維持できることを知りました。
レスポンシブデザインにすることがこんなにも難しいのかと肌で実感し、試行錯誤したことが良い体験として印象に残っています。
